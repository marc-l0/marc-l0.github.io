# Archivo de notas del portfolio

Estas cinco notas de mantenimiento se consolidaron en el tercer artículo del blog: `src/content/blog/tercer-post.md`.

Se conservan aquí como registro histórico y no se incluyen en la colección pública de artículos. Pueden describir estados intermedios que ya no aplican. Sus rutas anteriores redirigen a `/blog/tercer-post/` mediante `astro.config.mjs`.

Las nuevas entradas del blog deben centrarse en cambios importantes, proyectos y aprendizajes; los ajustes menores no necesitan un artículo independiente.
